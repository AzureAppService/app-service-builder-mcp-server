node client.mjs

Configure your server & understand its boundaries

server.mjs reads APP_API_TOKEN and the optional exact HTTPS PUBLIC_ORIGIN. Configure your own app, then restart locally or save and deploy a new version. This page cannot discover your fork or change deployment settings; never paste credentials here.

POST /mcp requires a Bearer token of at least 32 characters. Missing or short server configuration fails closed. Supplied origins must match the configured allowlist. No CORS access is granted.

GET and DELETE on /mcp return 405. No standalone event stream, resumability, OAuth server, or long-lived workload support is demonstrated.
