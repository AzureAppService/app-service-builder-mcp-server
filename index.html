Bring your client.

This page is a read-only guide, not a browser MCP client.

Start the server locally and set APP_API_TOKEN securely in your environment. From a terminal with the same token, run the included Node client:

node client.mjs

The client initializes, lists text_length, then calls it with Hello. Read the setup instructions ↗

Authentication and transport boundaries

POST /mcp requires a Bearer token of at least 32 characters. Missing or short server configuration fails closed. Supplied origins must match the configured allowlist. No CORS access is granted.

GET and DELETE on /mcp return 405. No standalone event stream, resumability, OAuth server, or long-lived workload support is demonstrated.
